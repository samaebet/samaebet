### AI Keylogger (Research Project)
`Python` `Multi-threading` `Pynput` `Ollama (Qwen2.5)`
Engineered a multi-threaded Python program to capture and log background keystroke data locally, then automated a local Ollama LLM to ingest raw logs every 2 minutes, extracting key data and generating summaries. Built as a defensive security/research exercise to better understand keylogger mechanics and AI-assisted log analysis.
